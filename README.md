# finance-design — React-прототип

Самостоятельный исследовательский репозиторий в `finance-app/research/`. Он не входит в `app/finance-client` и не подключён к общему деплою приложения.

Актуальные брендбук, UI Kit, 54 экрана и 7 сценариев находятся в одном React-проекте. Визуальный эталон — понравившийся пользователю первый HTML-прототип (`research/design/index.html`, `styles.css`, `prototype.js`); дополнительные 45 состояний происходят из файла [Figma](https://www.figma.com/design/ch4sqQeEeTasSQ7Bh6bEz8?node-id=0-1). Макет кликабельный, но не выполняет финансовых операций.

В мобильном просмотре можно выбрать валюту первого счёта (по умолчанию USD), переключать расход/доход/перевод в одной форме, открыть калькулятор нажатием на сумму (есть клавиша `000`), выбрать валюту и увидеть предварительный пересчёт. Экран валют поддерживает ручной курс, добавление кода валюты и обновление по API Frankfurter. Есть интерактивные экраны мультивалютного счёта, отчёта по категориям и месячного бюджета. Их денежные данные демонстрационные.

Раздел «Экраны» сразу открывается в режиме просмотра на весь браузер: телефон целиком вписывается в доступную высоту. Быстрые вкладки переключают базовый поток, выпадающий список содержит все 54 экрана, стрелки и клавиши ← → переходят к соседним. Кнопка «К разделам» возвращает к обычной странице. Переход между экранами не сбрасывает прокрутку страницы.

## Локально

```sh
npm ci
npm run dev
```

Откройте адрес, который напечатает Vite (обычно `http://localhost:5173`). Для проверки готовой сборки:

```sh
npm run build
npm run preview
```

`index.html` следует открывать через сервер, а не двойным кликом через `file://`: браузер блокирует ES-модули на локальном файловом протоколе.

## Docker

Из корня репозитория:

```sh
docker build -t finance-design-react .
docker run --rm -p 8080:80 finance-design-react
```

Откройте `http://localhost:8080`. Dockerfile собирает Vite-приложение на Node.js и отдаёт статические файлы через Nginx. Hash-маршруты позволяют открыть экран напрямую, например `http://localhost:8080/#screens/options`.

## Структура

| Путь | Назначение |
|---|---|
| `src/components/ui.jsx` | Общие React-компоненты дизайн-системы |
| `src/components/Phone.jsx` | Мобильный макет, собранный из этих компонентов |
| `src/components/FinanceFlows.jsx` | Интерактивные сценарии операций, валют, счетов, отчёта и бюджета |
| `src/pages/` | Brandbook, UI Kit, Экраны, Сценарии, Документация |
| `src/data/` | Содержание 54 состояний и маршруты из исходных макетов |
| `src/styles.css` | Токены и оформление компонентов |
| `DECISIONS.md` | Обоснование решений и ограничения |

Проверка карты экранов и переходов: `npm run check`. Проверка компиляции: `npm run build`.
